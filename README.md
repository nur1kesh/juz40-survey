# JUZ40 — курстан шыққан оқушыларға арналған сауалнама

Node.js 18+. Жалғыз тәуелділік — `pg` (PostgreSQL драйвері); файл режимінде `npm install`-сыз да жұмыс істейді.

## Іске қосу

0. Бір рет: `npm install` (PostgreSQL драйвері `pg` үшін).
1. `.env.example` файлын `.env` деп көшіріңіз және толтырыңыз:
   - `ADMIN_PASSWORD` — `/admin` бетіне кіру құпиясөзі
   - `OPENAI_API_KEY` — OpenAI кілті (тек серверде сақталады, браузерге берілмейді)
   - `OPENAI_MODEL` — модель атауы
2. `npm start`
3. Сауалнама: http://localhost:3000 · Аналитика: http://localhost:3000/admin

Дерекқор: `DATABASE_URL` болса — **PostgreSQL**, әйтпесе `data/db.json` файлы (тек әзірлеуге ыңғайлы). Өндіріс үшін PostgreSQL қолданыңыз.

## Мүмкіндіктер
- Оқушыға: 0–10 бағасы таңдағанда боялады; «Толықтай ақтады» емес болса себеп өрісі шығады; ұнаған/қиындық тізімі; қиындық бойынша толығырақ жазу.
- Админге: NPS, орташа баға, таралулар, динамика, әр жауапты AI-талдау, AI қорытынды, тақырыптар, әрекет жоспары, іздеу/сүзгі, Excel және CSV экспорт.
- **Жауап нөмірлері (#001…) тұрақты**: жауап өшірілгенде басқаларының нөмірі өзгермейді және өшкен нөмір қайта берілмейді — сондықтан сақталған AI-қорытындылар мен тақырыптардағы сілтемелер дұрыс қалады.

## Аналитика
- **Автоматты (AI-сіз):** NPS сегменттері, күшті/әлсіз жақтар (ұнады vs қиындық), апталық динамика, жиі сөздер.
- **AI (OpenAI):** әр жауапты талдау (категория, sentiment, маңыздылығы, кету себебі, алдын алуға бола ма, қайтару әлеуеті, ұсынылатын әрекет); тақырыптарға кластерлеу; деректен еркін сұрақ қою; жалпы қорытынды.

## Жұмыс барысы (бизнес-логика)
1. Оқушыларға сілтеме жіберіңіз. Ағымды/оқушыны белгілеу үшін `?ref=` қосыңыз: `https://сайт/?ref=поток-5`. Дереккөз жауап карточкасында және CSV-де көрінеді.
2. AI тек батырма арқылы жұмыс істейді (әр іске қосу алдында шамамен токен көрсетіліп, растау сұралады). Автоматты талдауды `AUTO_ANALYZE=1` қосады. Күндік лимит әдепкіде өшірулі; қосу үшін `AI_DAILY_TOKEN_LIMIT=300000` қойыңыз. Жұмсалған токен админ бетінде көрінеді.
3. Әр жауапты админкеде толық көруге болады: «AI-инсайт» бетінде санат, Sentiment және маңыздылығы бойынша (AI-талдау: кету себебі, ұсынылатын әрекет).
4. «Жауаптар» бетінде **күн мен уақыт аралығы** (Бастап / Дейін, жылдам түймелер: Бүгін, 7 күн, 30 күн): таңдалған аралық Excel және CSV жүктеуіне де қолданылады. Жоғарыда — кезең сүзгісі (7/30/90 күн), сұрыптау, **Excel (.xlsx)**, CSV және JSON сақтық көшірме («Жауаптар» бетінде). Excel файлында 2 парақ: «Жауаптар» (сүзгі, бекітілген тақырып, күндер сіздің уақыт белдеуіңізде) және «Қорытынды» (орташа баға, NPS, таралулар).

Қорғаныс: бот-тұзақ (honeypot), қайталанған жіберуден қорғаныс (әр форма үшін бірегей id), жіберу лимиті, CSV-формула инъекциясынан қорғау, оқушы мәтініндегі «нұсқауларды» AI орындамайды.
Оқушы формасы қараламаны (draft) браузерде сақтайды; жіберген соң қайта ашса, «рақмет» беті көрсетіледі.

## Тест деректері (админкені тексеру үшін)
- `node scripts/seed-demo.js` — 48 тест жауап (қазақша мәтіндер, 45 күнге таралған, түрлі баға/қиындықтар), AI-талдау үлгісі, қорытынды мен тақырыптар қосады. Саны: `--count=120`.
- `node scripts/seed-demo.js --remove` — тест деректерін өшіреді, **нағыз жауаптарға тимейді** (тест жазбалары `cid="demo-…"` және дереккөзі `demo-…` арқылы танылады).
- Бұл нағыз AI емес, дайын үлгілер; токен жұмсалмайды.

## Құрылым
- `xlsx.js` — сыртқы кітапханасыз .xlsx жазушы.
- `server.js` — HTTP сервер, API, OpenAI; `store.js` → `store-pg.js` (PostgreSQL) немесе `store-file.js` (JSON); `insights.js` — AI-тақырыптар, жоспар, сұрақ-жауап.
- `public/` — `index.html`+`survey.js` (оқушы), `admin.html`+`admin.js` (аналитика), `style.css`, `icons.js` (Lucide), `fonts/Onest.woff2` (қазақ әріптерін қамтиды).
- `test/smoke.test.js` — автотест. Пәрмендер: `npm start`, `npm run check` (синтаксис), `npm test` (файл режимі), `npm run test:pg` (PostgreSQL; `TEST_DATABASE_URL=postgres://… ` орнатыңыз, база UTF8 болуы керек). Барлығы 16 сценарий (PostgreSQL-да 15, біреуі тек файл режиміне арналған), нақты OpenAI-сыз; тесттер сіздің `.env` файлыңыздан тәуелсіз (`NO_DOTENV=1`).

## PostgreSQL
1. UTF8 кодтауымен база жасаңыз (**Windows-та әдепкі WIN1251 болуы мүмкін — онда Қ, Ғ, Ә әріптері сақталмайды**, сервер мұны тексеріп, тоқтайды):
   ```sql
   CREATE DATABASE juz40 ENCODING 'UTF8' TEMPLATE template0 LC_COLLATE 'C' LC_CTYPE 'C';
   ```
2. `.env` ішіне: `DATABASE_URL=postgres://user:pass@localhost:5432/juz40` (бұлттық базада `DATABASE_SSL=1`).
3. `npm start` — кестелерді сервер өзі жасайды (`responses`, `analysis`, `kv`, `ai_usage`).
4. **Ескі деректер.** Бос базаға алғаш қосылғанда `data/db.json` автоматты көшіріледі (бір транзакцияда), ескі файл `db.json.migrated-…` болып ауыстырылады. Өшіру: `MIGRATE_FROM_JSON=0`.
5. Сақтық көшірме: PostgreSQL құралдарымен (`pg_dump juz40 > backup.sql`) немесе хостинг көшірмелерімен. Админкедегі «Сақтық көшірме» түймесі барлық деректі JSON-ға шығарады.
6. `/healthz` базаға қосылымды да тексереді (503 — база қолжетімсіз). База өшіп қалса, сайт қатып қалмайды: 5 сек қосылу және 20 сек сұраныс таймауты бар, оқушыға «қайта жіберіп көріңіз» хабары көрсетіледі (қайталанған жіберу дубль жасамайды), статикалық беттер жұмысын жалғастырады.

Бір командамен (сайт + PostgreSQL): `docker compose up -d --build` (`.env` ішінде `POSTGRES_PASSWORD`, `ADMIN_PASSWORD` керек).

## Деректер қауіпсіздігі
- Файл режимінде: күніне 1 көшірме `data/backups/` ішіне (соңғы 14 күн). `db.json` бүлінсе сервер бос базамен үстінен жазбайды: көшірме жасап, қатемен тоқтайды.
- `.env` және `data/` `.gitignore`-да — git-ке түспейді.
- Қорғаныс: CSP және басқа тақырыптар, бот-тұзақ, қайталанған жіберуден қорғау, лимиттер, CSV-инъекциядан қорғау.

## Docker
```
docker build -t juz40-survey .
docker run -d -p 3000:3000 -v juz40data:/data -e ADMIN_PASSWORD=... -e OPENAI_API_KEY=... -e OPENAI_MODEL=gpt-5.6-luna -e TRUST_PROXY=1 juz40-survey
```

## Хостинг
Node-ды қолдайтын кез келген серверге (Render, Railway, VPS) жүктеңіз және PostgreSQL қосыңыз (`DATABASE_URL`). Файл режимінде `DATA_DIR` тұрақты дискіге бағытталуы керек. Прокси артында `TRUST_PROXY=1` қойыңыз (әйтпесе барлық оқушы бір IP болып көрінеді). Тексеру: `/healthz`.
